# Mimari

> Taslak — backend/database kurulum planlaması yapıldıkça güncellenecek.

## Bileşenler
- **mobile-android**, **mobile-ios**, **web** → `backend` API'sine HTTP üzerinden bağlanır.
- **backend** → `database` (PostgreSQL) ile konuşur.
- API sözleşmesi `docs/api-spec.yaml` içinde tanımlanır; tüm istemciler bu sözleşmeye göre geliştirilir.
